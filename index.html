Paste Helper Extension

Right-click text you've selected on any website and send it straight to RSVP4Dingus — no repeated "allow paste" prompts.

Desktop browsers only (Chrome or Edge). This does not work on iPhone or iPad.

This isn't published to the Chrome Web Store yet, so installing it takes a few manual steps:

  1. Download rsvp4dingus-paste-helper.zip
  2. Unzip the downloaded file.
  3. In Chrome or Edge, go to chrome://extensions (or edge://extensions).
  4. Locate Developer mode and turn it on (its position varies by browser).
  5. Click Load unpacked and select the unzipped folder — the one that directly contains a file named manifest.json, not a folder around it.

Chrome/Edge may warn that this is an unverified extension — expected for a personal, unpublished one, and safe to proceed.
